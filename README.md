# Awez Eh

The backend of Awez Eh ("What do you want?"), a city app for Sadat City, Egypt: real estate, craftsmen, restaurants, shops and pharmacies, second-hand items, a city guide and requests. A versioned JSON API for the mobile app and a Filament admin panel.

The application is set up by task 001. Until then this repository holds the plan:

- `CLAUDE.md`: the rules for everyone working on the code.
- `docs/ARCHITECTURE.md`: the design.
- `docs/BUILD_PLAN.md`: the order of the work.
- `docs/tasks/`: the briefs; `docs/reports/`: what was done.
